# Trabajo Práctico - Grafos

TP de la materia Programación 1 (Tecnicatura Superior en Programación).
Resolución de la teoría y la implementación en Python sobre grafos:
conceptos, clasificación y representación con listas y matrices de adyacencia.

## Contenido

- `grafos.py` - Funciones de listas de adyacencia y consultas
  (crear_listas_adyacencia, grado_nodo, son_adyacentes,
  crear_listas_adyacencia_dirigido, grado_entrada_salida).
- `grafos2.py` - Funciones de matriz de adyacencia
  (crear_matriz_adyacencia y su versión dirigida).
- `grafos3.py` - Ejercicio 12 integrador: sistema de delivery
  modelado como grafo dirigido (DAG).
- `Grafos TP Gonzalo_Tapia.docx` / `.pdf` - Documento con el TP resuelto completo.

## Cómo ejecutar

Cada archivo se corre con Python 3:

    python grafos.py
